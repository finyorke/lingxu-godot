# 《御剑灵墟》新版游戏设计文档

> 版本：2.0
> 更新日期：2026-06-11
> 游戏类型：2D 俯视角仙侠动作肉鸽 / 幸存者割草
> 文档用途：定义当前版本的核心体验、系统规则、数值框架、内容范围与后续设计方向。

---

## 1. 项目定位

《御剑灵墟》是一款 **2D 俯视角仙侠动作肉鸽 / 幸存者割草**。玩家扮演末代御剑修士 **云栖**，在灵气逆乱的灵墟中依靠走位生存、四件法器自动攻敌、五行灵根构筑与境界突破，撑过约 12 分钟的一局历劫。

核心体验目标：

- **御剑爽感**：玩家主要负责走位，法器自动锁敌、飞行、环绕、召唤或范围攻击。
- **构筑深度**：法器、道具、数值卡、灵根体质共同决定伤害乘区和流派方向。
- **仙侠仪式感**：灵根抉择、境界突破、机缘四选一、妖将压力点共同形成“修行历劫”的节奏。
- **强反馈战斗**：命中有 hitstop、屏震、剑光 FX、暴击动画、伤害飘字与敌人受击反馈。

---

## 2. 核心设计要点

当前版本的关键设计如下：

| 模块 | 新版设计 |
| --- | --- |
| 灵根抉择 | 不再强制“封 2 留 3”；现在是 **最多封印 2 道，最少 0 道**。保留灵根越多，池子越宽；封印越多，构筑更集中。 |
| 修行体质 | 新增 **五行灵根 / 单灵根 / 双修灵根** 体质选择，影响元素伤害倍率与互转规则。 |
| 多元素武器收益 | 当前装备法器覆盖的元素越多，总伤害倍率越高：1 系 100%，2 系 116%，3 系 132%，4 系 150%。 |
| 法器品阶 | 法器有 4 档品阶：凡品、灵品、法品、仙品；同名同品两件可合成更高品阶。 |
| 法器槽与备炼栏 | 角色有 4 个实装法器槽；槽满时不直接替换，新法器优先合成，其次进入 **2 格备炼栏**，再满则拒绝获得。 |
| 境界机缘 | 机缘四选一中先“选择”，但不立即退出；玩家可整理装备/道具，点击 **继续历练** 后才回到战斗。 |
| 机缘锁定 | 已选择一个机缘后，其他机缘可锁定到下一次；刷新不会替换锁定内容。 |
| 云游商会 | 每 60 秒出现一次，可用灵石购买。购买某格商品后，该位置淡入补一个新商品，而不是整页刷新。 |
| HUD 与 UI | 装备栏在左下角，道具栏显示已获道具；属性摘要移到右侧；中文字体和图标资产已正式化。 |
| 敌人行为 | 敌人不再只从屏幕外线性追击，新增场内预警圈刷怪、远程弹幕、冲锋、闪现、范围预警攻击。 |
| 暴击反馈 | 暴击触发专门的金色爆裂环、交叉剑痕、火花与“暴击”字样。 |

## 3. 世界观与美术基调

上古镇灵碑破裂后，灵气逆流，山河化为“灵墟”。草木、走兽、亡魂、遗剑皆被异化为妖。御剑诸宗几近覆灭，云栖作为末代御剑修士，持本命飞剑入墟斩妖，最终面对由万剑怨气孕生的 **噬灵剑魔**。

美术关键词：

anime cel-shaded illustration, clean line art, flat color with crisp highlight/shadow layers,
eastern xianxia / wuxia fantasy, jade-teal spiritual qi mist, ink-wash ruined landscape,
floating flying swords, five-element sword auras, ethereal and serene yet desolate

## 4. 单局流程

```text
主菜单 / 宗门遗址
  -> 灵根抉择：封印 0-2 道灵根，选择修行体质
  -> 灵墟战场：12 分钟历劫
      -> 自动法器战斗 + WASD 走位
      -> 击杀掉落灵气和灵石
      -> 升级触发境界机缘四选一
      -> 每 60 秒云游商会
      -> 3/6/9/12 分钟妖将压力点
  -> 道成 / 陨落 / 撤回结算
  -> 回宗门或继续下一劫
```

当前局内目标：撑过 **12:00** 即“道成”。3、6、9 分钟刷出赤睛妖蟒压力点，12 分钟刷出终局噬灵剑魔，同时到达道成结算条件。

## 5. 输入与控制

| 动作 | 默认输入 | 说明 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 核心操作，玩家主要通过走位生存。 |
| 踏罡 | Space | dash 位移，含无敌帧和冷却。 |
| 聚剑斩 | 鼠标左键 / J | 主动爆发，默认手动，可在设置中开启自动释放。 |
| 暂停 / 菜单 | Esc | 后续可扩展为隐藏属性详情页入口。 |
| UI 确认 | Enter / 鼠标 | 选择机缘、确认继续等。 |

设计原则：输出尽量自动化，操作压力集中在走位、闪避、择机爆发和构筑决策上。

## 6. 灵根抉择与修行体质

### 6.1 五行灵根

五行：金、木、水、火、土。

| 灵根 | 定位 | 核心关键词 |
| --- | --- | --- |
| 金 | 御剑输出 | 飞剑、贯穿、暴击、分裂、破甲 |
| 木 | 毒蛊万化 | 中毒、瘟疫、藤蔓、易伤、持续 AoE |
| 水 | 守一护体 | 护盾、冰寒、减速、冻结、牵引 |
| 火 | 焚天爆发 | 灼烧、爆炸、暴击、残血处决 |
| 土 | 镇岳厚土 | 护甲、震荡、击退、石化、召唤 |

### 6.2 封印规则

- 开局可封印 **0 到 2** 道灵根。
- 未封印灵根成为本局生效灵根。
- 商店、境界机缘、Boss 掉落、元素道具、元素技能均只围绕本局生效灵根出现。
- 中性道具与通用数值卡始终可出现。
- 封印越少，选择池越宽，更多元素倍率机会；封印越多，构筑更集中、目标更明确。

### 6.3 修行体质

| 体质 | 当前规则 | 设计意图 |
| --- | --- | --- |
| 五行灵根 | 五系元素伤害各 +8%；某元素伤害会获得其他元素直接加成的 30% 互转，五行互济可继续提高互转。 | 适合多元素武器和泛用构筑。 |
| 单灵根 | 对应元素伤害乘区 +35%；异系没有体质倍率，只吃基础伤害和显式获得的数值加成。 | 适合单系专精与极限伤害。 |
| 双修灵根 | 两个指定元素各 +24%；两系之间可吃另一系直接元素加成的 35% 互转。 | 适合 2+2 法器搭配和相生路线。 |

### 6.4 多元素法器倍率

根据当前 **已装备法器槽** 覆盖的不同元素数量，获得全局伤害倍率：

| 已装备元素数 | 总伤害倍率 |
| ---: | ---: |
| 1 | 100% |
| 2 | 116% |
| 3 | 132% |
| 4 | 150% |

当前法器槽上限为 4，所以实战最高按 4 系 150% 结算。该机制鼓励玩家用多元素法器拓宽伤害覆盖面。

### 6.5 相生连招

五行相生关系：

```text
木生火 -> 火生土 -> 土生金 -> 金生水 -> 水生木
```

灵根抉择页面会根据本局生效灵根显示可触发的相生路线。相生是构筑提示和后续扩展方向：当前版本已经展示路线信息，后续可继续落地更具体的 2+2 套装技能。

## 8. 战斗系统

### 8.1 基础手感

- 战场为椭圆边界，玩家在边界内移动。
- 法器自动锁敌，按自身类型发射、环绕、范围爆发或召唤。
- 命中触发 hitstop、屏震、元素 FX、伤害飘字。
- 暴击触发金色暴击动画和“暴击”字样。
- 聚剑斩是主动爆发技能，范围受角色“范围”属性影响。
- 踏罡提供位移、无敌帧和冷却管理。

### 8.2 伤害计算

当前核心公式可概括为：

```text
基础伤害
+ 剑意 * 法器剑意成长
+ 法力 * 法器法力成长
+ 御器之力 * 法器御器成长
* (1 + 全伤)
* 体质倍率
* (1 + 元素伤害互转后结果 + 元素通用加成)
* 多元素法器倍率
* 法器品阶倍率
* 暴击 / 处决 / 命中特效修正
```

法器品阶倍率：

| 品阶 | 名称 | 倍率 |
| ---: | --- | ---: |
| 1 | 凡品 | 1.00x |
| 2 | 灵品 | 1.70x |
| 3 | 法品 | 2.89x |
| 4 | 仙品 | 4.91x |

### 8.3 法器获得与合成

获得法器时按以下顺序处理：

1. 如果已有同名同品法器，直接合成并升 1 品。
2. 否则，如果 4 个法器槽未满，装备到法器槽。
3. 否则，如果 2 格备炼栏未满，进入备炼栏。
4. 否则拒绝获得，提示玩家先合并、出售或拖拽整理。

玩家可在机缘界面拖拽法器，在法器槽与备炼栏之间互换，也可以出售换灵石。

## 11. 境界、机缘与商店

### 11.1 境界

| 境界 | 等级 | 奖励 |
| --- | ---: | --- |
| 练气 | 1 | 初始境界。 |
| 筑基 | 5 | 回满生命。 |
| 金丹 | 10 | 剑刃额外表现 / 品质提升。 |
| 元婴 | 16 | 全伤 +15%，护体灵盾 +30。 |
| 化神 | 23 | 允许神品法器，剑气分裂方向开启。 |

升级触发“境界机缘”四选一；跨境界触发渡劫反馈和“机缘大开”。

### 11.2 境界机缘

- 每次升级打开四选一。
- 玩家只能选择一个机缘。
- 第一次刷新免费；第二次起每次消耗 8 灵石。
- 选择后不会立刻退出，玩家可整理法器槽、备炼栏和道具栏。
- 选择一个后，其他机缘可锁定到下一次。
- 点击 **继续历练** 后正式获得已选机缘并回到战斗。

### 11.3 云游商会

- 每 60 秒出现一次。
- 商品池和机缘池类似，但需要花灵石购买。
- 锁定商品会在下次商店保留。
- 刷新不会替换锁定商品。
- 买走一个商品后，该位置淡入补一个新商品，而不是整页刷新。

### 11.4 候选池过滤

候选池由本局生效灵根过滤：

- 武器：只出现未封印灵根对应的元素武器。
- 元素道具：只出现未封印灵根对应的元素道具。
- 元素心法：只出现未封印灵根对应的元素心法。
- 中性道具、通用心法不受过滤。
- 化神前神品法器不出现。

## 15. 内容数据与扩展原则

游戏内容应以结构化数据维护，保证数值调整、内容扩展和版本平衡不需要改写核心玩法规则。

| 数据域 | 作用 |
| --- | --- |
| 基础属性 | 气血、护盾、法器槽、背包、闪避、经验曲线等角色基础规则。 |
| 角色 | 可选角色、初始属性、起始法器和角色特性。 |
| 法器 | 法器元素、攻击方式、冷却、射程、伤害、品阶成长和特效表现。 |
| 法宝 | 局内被动道具、元素分类、叠加规则和数值收益。 |
| 心法 / 数值卡 | 境界机缘中的成长卡、通用强化和灵根流派强化。 |
| 敌人与 Boss | 敌人属性、移动方式、攻击方式、掉落、精英和 Boss 模板。 |
| 刷怪与地图 | 战场尺寸、波次曲线、场内预警、Boss 时间点和场上数量上限。 |
| 境界奖励 | 境界等级、突破条件、固定奖励和额外规则解锁。 |
| 机缘与商店 | 四选一池子、锁定规则、刷新价格、商品价格和购买替换规则。 |
| 起始法器池 | 新局可选法器的优先级、元素覆盖和初期构筑引导。 |
| 美术资源 | 角色、敌人、法器、图标、特效和 UI 资源的统一命名与尺寸规范。 |

扩展原则：

- 新增内容优先复用既有元素、品阶、标签和掉落规则。
- 新法器必须明确攻击方式、元素、成长曲线、特效辨识度和构筑定位。
- 新敌人必须明确压力来源，避免只通过堆生命和伤害提升难度。
- 新心法和法宝应服务某个可读流派，避免出现无差别的纯数值膨胀。

## 17. 后续设计方向与文档迭代计划

后续不建议直接把功能清单继续堆长，而应先用统一世界观把各系统串起来，再逐章补齐可开发、可验收的规格。设计文档的迭代顺序建议为：**世界观主轴 -> 系统叙事映射 -> 近期玩法闭环 -> 内容扩展 -> 数值与验收**。

### 17.1 统一世界观主轴

建议把《御剑灵墟》的长期设定收束为一句话：

**镇灵碑破裂后，五行灵脉倒灌成灾，灵墟不断吞没旧宗门；云栖不是单纯清怪，而是在每一次入墟中回收失序灵脉、修补镇灵残阵，并逐步追查噬灵剑魔与万剑冢的成因。**

这个主轴可以把当前玩法中的关键名词统一解释：

| 玩法名词 | 世界观解释 | 后续用途 |
| --- | --- | --- |
| 灵根封印 | 入墟前主动收束自身道途，避免被逆乱五行反噬。 | 解释为什么本局池子会变窄，也能引出挑战词缀。 |
| 修行体质 | 云栖对五行逆流的适应方式。 | 作为构筑风格的叙事标签，而不是纯数值选项。 |
| 境界机缘 | 灵墟碎片中的旧宗门传承、残阵回响或妖物遗蜕。 | 让四选一卡牌有来源，后续可做事件卡。 |
| 云游商会 | 在灵墟边缘活动的散修商队，贩卖从废宗门中回收的法器。 | 给局内经济和商品刷新一个稳定身份。 |
| 灵玉 / 精魄 | 灵玉是净化后的灵脉结晶，精魄是妖将残留的本源。 | 支撑洞府修行和局外成长。 |
| Boss 压力点 | 灵墟深处的守阵妖将逐层阻断云栖修补镇灵残阵。 | 方便扩展 3/6/9/12 分钟不同 Boss。 |

### 17.2 文档优化步骤

1. **做现状对齐**：先把本文档、旧版 SPEC、`Data/*.json` 与当前 Godot 实装逐项核对，标记“已实现 / 设计中 / 已过时”。任何新设定都应先落到现有系统名词上。
2. **补世界观词典**：新增或扩写“世界观与术语”小节，固定镇灵碑、灵墟、万剑冢、云栖、商会、五行灵脉、灵玉、精魄等名词，避免后续章节各写各的。
3. **重写系统动机**：在灵根、体质、法器、境界、商店、洞府等章节开头补一段“为什么它存在于世界中”，让玩法规则和仙侠语感一致。
4. **拆分近期路线图**：把后续方向拆成 P0 / P1 / P2，P0 只放能让当前版本更完整的闭环，不把长期想法挤进短期实现。
5. **补内容模板**：为 Boss、敌人、法器、法宝、事件、局外强化建立统一模板：定位、世界观来源、玩法压力、数据字段、验收点。
6. **建立设计验收**：每次改文档后同步更新第 18 节验收清单，确保文档不是概念稿，而是能直接指导实现和测试。

### 17.3 近期优先级

P0 优先补齐当前简单版本的闭环：

1. **背包升级闭环**：当前已有容量上限规则，需补齐局内花费灵石升级 5 -> 10 的流程，并说明这代表云游商会为云栖扩展“乾坤囊”。
2. **相生连招实装**：把灵根抉择页的相生预览转化为明确 2+2 装配效果，每条相生都需要一个名字、触发条件、效果、FX 方向和验收点。
3. **完整属性页**：将右侧摘要升级为 Esc 可打开的完整角色面板，优先保证构筑反馈清楚。
4. **数值仿真与平衡**：重点验证 XP 曲线、化神到达时间、法器品阶倍率、商店灵石收入和多元素倍率。

P1 用于扩展内容和复玩性：

1. **Boss 多样化**：当前 3/6/9 分钟都使用赤睛妖蟒，可扩展为三位守阵妖将加终局噬灵剑魔，并让每个 Boss 对应一种五行失序主题。
2. **洞府修行**：把灵玉、精魄接入局外法宝强化或永久微成长，定位为云栖在宗门遗址中修补镇灵残阵。
3. **云游商会事件化**：商店除商品外，可少量出现“旧宗门遗物”“散修委托”“残阵抉择”等事件卡。
4. **音频系统**：补齐法器、命中、暴击、渡劫、商店和 Boss 音效，用声音强化境界和五行差异。

P2 用于长期版本目标：

1. **无尽模式**：12 分钟道成后可选择继续深入灵墟，目标从通关转为高分和极限构筑。
2. **地图层级**：从单一灵墟战场扩展为旧宗门、万剑冢、灵脉裂隙等主题地图。
3. **角色与传承**：在云栖稳定后再考虑其他修士或传承，不宜过早稀释当前核心。
4. **动画质量继续提升**：角色、武器、敌人与 Boss 的连续帧动画可继续替换当前轻量表现。

### 17.4 第一轮文档改造建议

第一轮只做设计文档，不急着扩代码，建议拆成三次小改：

1. **世界观统一稿**：扩写第 3 节，定下灵墟成因、五行逆流、宗门遗址、万剑冢、云栖目标和商会定位。
2. **P0 系统规格稿**：扩写背包升级、相生连招、完整属性页和数值仿真四块，补到可直接开发的程度。
3. **内容扩展模板稿**：新增 Boss / 敌人 / 法器 / 事件卡模板，并先用 3 个 Boss 样例验证模板是否好用。
