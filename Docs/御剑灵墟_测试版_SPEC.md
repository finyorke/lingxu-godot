## 1. 产品定位与设计目标

### 1.1 一句话

天地灵气逆乱、万物化妖的「灵墟」中，末代御剑修士云栖御使本命飞剑与多件法器结阵斩妖——以**全自动御剑战斗 + 走位生存 + 法器多槽构筑 + 跨境界渡劫质变**形成仙侠肉鸽循环。

### 1.2 三个核心体验柱

1. **御剑的浪漫**：主角几乎不手动挥砍。本命剑环身自守，**4 件法器**全自动锁敌斩杀。爽点是"我御使的剑阵越来越大、剑光铺满全屏"，而非手速。手动集中在**走位** + 一个可选爆发键。
2. **构筑的深度**：法器分五行、分品阶、各吃不同属性成长；同系多件触发套装共鸣。配一张透明属性面板，每次升级、每件法宝都精确放大某条流派。
3. **境界的仪式感**：升级四选一带来横向变化；每跨一个大境界（练气→筑基→金丹→元婴→化神）触发全屏**渡劫**——剑芒变色、属性跃升，并紧接一次强化采购。

### 1.3 本版（测试版）的设计目标与收敛

本版是一个**刻意收敛的子集**，用更小、更可控的组合空间先把循环跑通、把数值调顺：

- 元素：**仅五行（金木水火土）5 种**（无雷系）。
- 武器：**每元素 7 件**，共 35 件。
- 武器槽：**4**。
- 角色：**仅云栖 1 个**（无择道选角）。
- 入墟前新增**灵根抉择**：封印 2 道灵根、留 3 道入墟 → 商店只刷这 3 系的武器/道具（缩小随机池，便于设计平衡）。
- 道具：**15 件已定义**；背包初始 **5 格、上限 10、可升级**。

> 「理想完整版」尚有更多武器/角色/雷系等扩展空间，但**不属于本版交付范围**，实现时无需考虑。

## 5. 输入与控制

### 5.1 InputMap（`project.godot` `[input]` 段）

| Action | 键位 | 用途 |
| --- | --- | --- |
| `move_*` | WASD / 方向键 | 走位（唯一高频操作） |
| `dash` | Space | **踏罡**：身法闪避，无敌帧 + CD |
| `sword_burst` | 鼠标左键 / J | **御剑·聚剑斩**：可选爆发主动键（CD，非必须） |
| `skill_q/e/r` | Q / E / R | 解锁后的主动术法（默认自动循环）；UI 确认·重抽 |
| `pause` | Esc | 暂停 / 撤回 |
| `ui_select` | Enter | UI 确认 |

> **设计要点**：左键不是主要输出。日常输出完全由 4 件自动法器承担。**少手动、多走位**是本作操作哲学。

### 5.2 朝向与锁敌

- **本体朝向 = 移动方向**（静止保持上一朝向）。
- 法器/剑灵**自动锁敌**，玩家不瞄准。
- 仅按 `sword_burst` 时以"鼠标方向 / 最近敌群质心"为爆发方向。
- 四朝向 sprite 选择：

```gdscript
if abs(vec.x) > abs(vec.y):
    facing = "right" if vec.x > 0 else "left"
else:
    facing = "down" if vec.y > 0 else "up"
```

### 5.3 自动化开关（`SaveSystem.settings`）

- `auto_burst`（默认关）：聚剑斩 CD 就绪即自动释放，纯走位玩。
- `auto_skill`（默认开）：解锁的 Q/E/R 主动术法自动循环。
- 自动化**不接管走位**——走位永远是玩家的事。

## 6. 灵根抉择（本版核心新机制）

### 6.1 设定与动机

修士天生有「灵根」，决定能修炼哪几系剑道。云栖虽具五灵根，但**入墟前须封印其中两道**——道途专一，方能精进。

- **玩法动机**：用开局抉择把本局构筑空间从 5 系收窄到 3 系。
- **设计动机**：商店刷新池随之缩小（只剩 3 系武器/道具），便于设计与平衡。

### 6.2 流程（RootChoice 页，替代择道选角页）

```
主菜单[入墟历劫]
   ▼
灵根抉择页
   ┌─────────────────────────────────────────┐
   │ 执剑人：云栖（唯一）                       │
   │ 五灵根：金 ● 木 ● 水 ● 火 ● 土 ●          │
   │ 请封印两道灵根（点击置灰）：               │
   │   金 [封]  木 [✓]  水 [封]  火 [✓]  土 [✓] │
   │ → 本局灵根：木 / 火 / 土                    │
   │ 提示：商店只会出现【木火土】的武器与道具    │
   │ [随机抉择]            [确认 · 入墟]         │
   └─────────────────────────────────────────┘
   ▼
灵墟战场（active_roots = [wood, fire, earth]）
```

### 6.3 规则

- 必须**正好封印 2 道**，留 **3 道激活灵根**（`active_roots`，长度恒为 3），封印后整局锁定不可改。
- **影响范围**（凡是"按元素随机"的池子都过滤）：
  1. 机缘集市 / 机缘大开的**武器**候选，只来自 3 激活灵根。
  2. 机缘集市的**带元素标签道具**候选，只来自 3 激活灵根；**中性道具（无元素）始终可出**。
  3. 主动技能 / 心法卡：按激活灵根过滤元素系卡；**通用(stat)卡始终可出**。
  4. Boss 的"煞气属性克制"（§16.2 相克 +15%）：若克制属性恰被封印，则该局吃不到这条克制（抉择的代价）。
- **五行相生连招**（§16.2）：仅在激活灵根中两两相生时才可能触发。**抉择即在选连招**。

### 6.4 数据（运行时字段，见 §26）

```jsonc
// GameState 运行时 / RunConfig
{
  "character": "yunxi",
  "active_roots": ["wood", "fire", "earth"],   // 长度恒为 3
  "sealed_roots": ["metal", "water"]           // = 五行 \ active_roots
}
```

> 元素 id 约定：`metal 金 / wood 木 / water 水 / fire 火 / earth 土`。

### 6.5 抉择页的信息呈现与策略（关键 · 防止盲选）

> **问题**：新手第一次入墟就要封 2 道灵根，但此时他对元素一无所知。抉择页**必须给足信息**，否则就是逼玩家瞎猜。

抉择页（RootChoice）每个灵根下显示一行**身份标签**与**该系核心打法**：

| 灵根 | 一行身份 | 核心打法 |
| --- | --- | --- |
| 金·御剑 | 飞剑·贯穿·高频单体 | 直接输出、暴击斩杀 |
| 木·毒蛊 | 中毒·瘟疫·持续 AoE | DoT 滚雪球、群体易伤 |
| 水·守护 | 护盾·冰寒·减速 | 续航肉盾、控场 |
| 火·焚天 | 灼烧·爆发·斩杀 | 高爆发、残血处决 |
| 土·镇岳 | 护甲·震荡·石化·召唤 | 控场坦克、召土傀 |

**动态预览（随当前选择实时刷新）**：

- 顶部一行"**本局可触发的相生连招**"，列出 3 激活灵根之间所有可能的相生（见 §16.2），并标注"需 2+2 装配开启"。
- 因 4 槽限制（见 §8.4），**一局最多同时开 1 个相生**；但若 3 系两两相生数 ≥2，则可在局内**通过换装在不同相生间切换**——这正是"留相邻三系 vs 留分散三系"的策略差别：
  - **相邻三系**（如 木火土 / 水木火 / 火土金 …）→ 含 **2 个相生**，局内可灵活切换，构筑弹性大。
  - **分散三系**（如 木土水 / 金木火 …）→ 仅 **1 个相生**，路线更窄但更聚焦。
- **首通推荐**：默认高亮"留 **金火土**（输出+处决+控场坦克，含 火生土 1 相生，容错高）"，并允许一键 [随机抉择]。

> 设计意图：把"开局盲选"改成"开局读三行字就能做的有信息决策"，并让抉择真正影响构筑弹性（相生数量），而不只是换一批武器图标。

## 8. 法器系统（4 槽 · 核心机制）

> 本作灵魂。玩家不"挥砍"，而是**御使一组法器全自动作战**——4 个法器槽里各放一件具体法器。

### 8.1 法器槽

| 项 | 规则 |
| --- | --- |
| 槽位数 | **4** |
| 开火 | 全自动锁敌，玩家不瞄准、不点击（少手动核心） |
| 锁敌策略 | 每件法器自带：nearest 最近 / lowest 血最低 / densest 最密 / farthest 最远 / self 身周 / auto 自律 |
| 升阶 | **2 件同名同品 → 合成高 1 品**（凡→灵→法→仙，共 4 品），威力随品 ×1.7；有空槽可选择不合 |
| 神品⭐ | 每元素 1 件，绑定周期大招，**仅化神境可出** |
| 来源 | 机缘集市 / 机缘大开 / Boss 掉落，**仅限 3 激活灵根**（§18） |

> 本命剑（环身自守，§10.1）独立于 4 法器槽之外，是保底近战，不占槽。

### 8.2 五行类别与成长源

每件法器属一种五行，决定它吃哪条属性成长、触发哪套套装共鸣：

| 属性 | 主成长源 | 代表法器 | 效果 |
| --- | --- | --- | --- |
| 金·御剑 | 剑意 | 贯日剑 / 御空剑雨 / 万剑幡 | 高频锁敌斩、贯穿；万剑幡吃御器召剑群 |
| 木·蛊器 | 法力 / 灵蕴 | 噬灵藤 / 万化蛊瓶 | 附毒、铺毒域、瘟疫 |
| 水·守器 | 御器 / 剑意 | 玄龟符 / 止水镜 | 生护体灵盾、格挡反弹、冰寒减速 |
| 火·焰器 | 法力 / 灵蕴 | 焚天符 / 业火刀 | 灼烧 DoT、近身爆 |

### 8.3 法器伤害成长（核心公式）

每件法器有成长系数 `scale{}`，伤害 = 基础 + 各属性 × 系数，再过乘区（完整伤害链见 §13）：

```text
raw = base_tier
    + sword_power × scale.sword      # 飞剑类高
    + spell_power × scale.spell      # 符箓类高
    + engineering × scale.eng        # 剑阵/傀儡/召唤类高
hit = raw × (1 + damage_pct) × (1 + element_pct if elemental)
if crit: hit ×= crit_mult(1.85)
```

> 飞剑吃"剑意"、符箓吃"法力"、召唤吃"御器之力"——不同流派吃不同属性，互不打架。

### 8.4 五行套装共鸣（2 / 4 件触发）

> 4 个槽最多堆 4 件同元素。阈值为 **2 件（入门）/ 4 件（纯色专精）**。

| 元素 | 2 件 | 4 件（满槽纯色） |
| --- | --- | --- |
| 金 | 全飞剑伤 +10% | 飞剑命中"剑分两仪"（分裂小剑气） |
| 木 | 中毒可传染相邻敌 | 中毒敌易伤 +15% |
| 水 | 每 6s 生成一层护体灵盾 | 灵盾破裂时 r=150 范围爆伤 |
| 火 | 灼烧 DPS +25% | 灼烧敌死亡引燃周围 |
| 土 | 受击积甲（每受击 +1，上限 +8） | 命中有概率短暂石化 + 震荡波连锁 |

**4 槽下的构筑数学（核心，务必实现一致）**：

| 装配 | 套装共鸣 | 相生连招（§16.2） | 定位 |
| --- | --- | --- | --- |
| **4 纯色** | 该系 2 件 + 4 件**全开** | ✗（相生需两系各 ≥2 件） | 单系**深度**上限 |
| **2 + 2** | 两系各得 2 件共鸣 | ✓ **1 个**（若两系相生） | **联动**：双系共鸣 + 相生 |
| 3 + 1 | 仅 3 系的 2 件共鸣（无 4 件，3 件不解锁额外档） | ✗ | 一般弱于上两者 |
| 1+1+1+1 | 无 | ✗ | 不推荐 |

- **关键约束**：相生连招要求"相生的两系各 ≥2 件" = 至少 `2+2`，**恰好占满 4 槽**。因此**一局最多同时激活 1 个相生连招**（开 2 个要 6 槽，本版做不到）。
- **平衡意图**：`4 纯色`（深度）与 `2+2`（双共鸣+相生）刻意做成对位的两强解，不让纯色成为唯一最优。强度靠 playtest 调"4 件效果"与"相生连招数值"两个旋钮，目标是两条路线 DPS/生存大致同档。
- 套装共鸣与相生连招可叠加。

## 13. 伤害系统与属性结算

### 13.1 完整伤害链

```text
dmg = weapon_raw(§8.3) × (1 + damage_pct)
if elemental:        dmg ×= 1 + element_pct
if hp_ratio < 0.35:  dmg ×= 1 + low_hp_damage            # 残血反扑（心法解锁）
if combo > 0:        dmg ×= 1 + min(0.45, combo×combo_damage)  # 连斩
if target_poisoned and kind != poison_dot: dmg ×= 1 + poison_vuln  # 木·易伤
if fire_execute and hp_ratio <= 0.25:  dmg ×= 1.75; force_crit    # 火·斩杀
if crit:  dmg ×= 1.85
命中后：lifesteal 回血 = dmg × lifesteal%
```

参考常量：`low_hp_damage=0.18`（心法）、`combo_damage=0.01`、`poison_vuln=0.15`（木 4 件）。

### 13.2 状态

| --- | --- | --- |
| 灼烧 | 火伤 | 持续火 DPS，可叠，上限 70 |

状态 tick 间隔 0.35s。

### 13.3 减伤与闪避

```text

```

## 16. 机缘集市与五行剑道（升级四选一）

### 16.1 机缘集市（每次升级触发）

灵气满 → 短暂停（`get_tree().paused=true`）→ 开**机缘集市**：同一面板既是"四选一抽取"又是"小商店"。

**四选一·混合池**：刷 4 张机缘，类型混合，都带品阶（凡/灵/法/仙/神品，边框=品阶色）：

| 类型 | 占比 | 内容 | 去向 |
| --- | --- | --- | --- |
| 仙丹（属性） | ~35% | 加属性面板某条，品阶决定数值 | 即时生效 |
| 主动技能 | ~20% | 获得新主动 / +充能层 / −耗时 / +范围（§10.3） | 技能槽(3+1) |
| 武器（法器） | ~25% | 五行法器，品阶 凡/灵/法/仙 | **4 武器槽** |
| 道具 | ~12% | 被动法宝，品阶 凡/灵/法 | 背包格 |
| 心法 | ~8% | 跨流派形态、相生强化（§16.3） | 即时生效 |

> 所有"武器/道具/技能/心法"候选先按 `active_roots` 过滤（§18）。

**仙丹品阶 → 数值**（同名仙丹按品阶给不同值）：

| 仙丹 | 凡品 | 灵品 | 法品 | 仙品 | 神品 |
| --- | --- | --- | --- | --- | --- |
| 凝血丹(气血) | +1 | +2 | +3 | +4 | +6 |
| 通用倍率 | ×1 | ×2 | ×3 | ×4 | ×6（稀有） |

**集市操作（同一面板）**：

- **选取**：点一张机缘获得（武器入武器槽、道具入背包、仙丹/技能/心法即时生效）。
- **刷新**：花灵石重刷 4 张，`reroll_cost = 2 + 本次刷新次数`（离开集市重置）。
- **回收**：把已有武器/道具回收换灵石（返还约 50% 购置价）——腾槽位、换灵石两用。
- **锁定**：把某张机缘锁住，带到下次集市（占位，不退款）。
- **购买背包容量**：花灵石 +1 背包格（§19.3）。
- **跳过**：不选，换回血 18 + 灵石 2。

**槽位与合成**：

- 武器 → **4 武器槽**；道具 → **背包容量格**（`bag_capacity`）。
- **二合一升阶**：两件同名同品 → 合成高一品；武器 4 品（凡→灵→法→仙）、道具 3 品（凡→灵→法）。
- **有空槽时可选择不合**：两件铺场 vs 合一件提质，是构筑取舍。

**XP 曲线**（近线性，后期不卡）：

```text
xp_next(L) = 12 + 8×L             # L = 当前等级
```

参考：L1→2=20，L10=92，L20=172，L30=252。系数(12/8)是纯数值旋钮，实测可调。

**境界节奏锚定（必须满足，否则系统失衡）**：神品武器与"剑分两仪"等终局质变**全部锁在化神（Lv23）后**，所以**化神必须可达且不能太早**。目标节奏（在标准刷怪曲线下实测校准 `xp_curve`）：

| 境界 | 目标触发时间 | 说明 |
| --- | --- | --- |
| 筑基 Lv5 | ~1:30 | 早期小高潮 |
| 金丹 Lv10 | ~4:00 | 构筑成型 |
| 元婴 Lv16 | ~7:30 | 套装/相生成型 |
| 化神 Lv23 | **~10:00–11:00** | 神品解锁，赶在终局剑魔(12:00)前 |

> **风险**：线性曲线极可能让前期升级过快（半场就化神，后半场再无渡劫高潮）或过慢（打不到化神→神品成死内容）。**M4 验收前必须用刷怪曲线 + 平均击杀效率做一次经验收入仿真**，反推/分段调整 `xp_curve`，命中上表节奏（可接受 ±1 分钟）。

### 16.2 五行相生相克（共鸣层）

采用正统五行相生相克（金木水火土成环）：

- **相生循环**：木生火 → 火生土 → 土生金 → 金生水 → 水生木。
- **相克循环**：木克土 → 土克水 → 水克火 → 火克金 → 金克木。
- **相生连招**（同时持有相生两系达阈值触发被动；**仅在激活灵根之间生效**，§6.3）：
  - 木生火：中毒敌受火伤 +20%。
  - 火生土：灼烧敌死亡时生成一圈震荡波。

### 16.4 机缘权重与凑装规则

> 目标：既能凑到同名两件→合阶，又能收集到同系但未拥有的武器。**加权挂在"系/属性"上，而非具体某把**。

**武器刷新权重**：

```text
weight(w) = 品阶基础权重(按当前境界)
          × 系亲和(w.element)
          × 拥有/新增系数(w)

# 前置过滤：w.element ∈ active_roots（§18）；神品仅化神可入池
系亲和(e)   = 1 + 0.25 × 你该系已投入件数(武器+心法计数)   # 封顶 ×2.5
拥有/新增   = 已拥有同系武器 ×1.4   # 利于凑同名合阶
              未拥有同系武器 ×1.2   # 利于补全流派
              非投入系武器   ×1.0
空槽加成     若有空武器槽：未拥有武器额外 ×1.3
气运 luck    额外抬高高品阶与心仪系出现率
```

**三道保障（不靠纯运气）**：

1. **保底新货（含枯竭降级）**：每次集市 4 张中至少 1 张是你尚未拥有的武器（范围限激活灵根内）。**当激活灵根内的非神品武器已全部拥有时，保底依次降级**：① 改保底一张"可合阶的同名重复件"（助升品）→ ② 化神后改保底一张神品 → ③ 仍无可保则取消该保底位，正常按权重刷（不卡死）。
2. **锁定**：心仪机缘可锁住带到下次集市。
3. **回收 + 刷新**：回收冗余换灵石定向刷；机缘大开免费首刷 + 品阶上调，是凑装黄金窗口。

> **系亲和 snowball 注记**：本版池子小（21 武器），`系亲和 ×1.4(已拥有)` 会加速抱团成纯色——这是**有意的**（让玩家快速成型）；但保底新货 + 未拥有 ×1.2 + 空槽 ×1.3 共同保证你**仍能见到想要的第二系武器**去走 2+2，不会被纯色刷屏锁死。若 playtest 发现纯色出现率压制 2+2，把"系亲和"封顶从 ×2.5 下调到 ×1.8。

**合成规则**：A 案——两件同名同品 → 合成高一品（保留流派纯度）；不放宽为"任意同系同阶可合"。

## 19. 道具（法宝）系统 · 15 件 + 背包

### 19.1 通则

- **被动生效**：装入背包即生效，不占武器槽。
- **品阶 3 品**（凡/灵/法），同名同品 2 合 1 升阶（A 案）；高品阶数值 ×1.7。
- **占位**：多数道具占 **1 格**；**3 件 build-defining 道具占 2 格**（凝神丹方/两仪剑佩/斩杀玉），制造背包取舍。
- **占 2 格道具的合成**：为避免"同时塞 2 件占 4 格"挤爆背包，2 格道具采用**就地合成**——第 2 件同名同品被抽到时，集市直接提供"合阶"按钮（消耗它升级包内那件），**不要求两件同时在包内**；包内始终只占 2 格。
- **元素标签**：分**中性**（无元素，始终可刷）与**元素系**（带元素，受灵根抉择过滤，§18）。

## 20. 掉落与三币经济

### 20.1 三币职责（UI 必须分清）

| 货币 | 视觉 | 用途 | 留存 |
| --- | --- | --- | --- |
| **灵气** | 青色菱形晶 | 升级 → 机缘集市四选一 | 局内即时消耗 |
| **灵石** | 金色菱形晶 | **局内集市货币**（采购/刷新/购容量；回收返还） | 本局有效 |
| **灵玉 + 精魄** | 局末结算获得 | **局外**：灵玉=货币(强化法宝)、精魄=强化材料 | 永久存档 |

### 20.2 掉落规则

- 妖物死亡必掉灵气晶（`gain_qi(amount × qi_gain)`）。
- 16% 概率掉灵石（`8 + int(run_time/240)`），Boss 必掉（`24 + boss_index×8`）。
- 精英 40% / Boss 100% 掉精魄（局末结算入存档）。
- 3.5% 概率掉回灵丹（回血 14）。

### 20.3 摄物拾取（磁吸）

| 阶段 | 行为 |
| --- | --- |
| 出生 0-150ms | 随机方向 220px/s 蹦出 |
| 减速 | `velocity.lerp(0, 0.06)` |
| 进入摄物半径(`pickup_radius`) | 永久吸引 |
| 吸引中 | `velocity.lerp(dir×540, 0.18)` |
| 触碰玩家 | 收取 + free |

### 20.4 局末结算

```text
if 道成: earned += 80

```

- 元素：背景水墨遮罩 / 标题大字（陨落 / 历劫终了）/ **致命一击条**（致命敌头像+招式+伤害）/ **溯源列表**（最近 3~5 条受击）/ 点击提示（朱红印章）。
- 数据来源：玩家维护最近 5 秒受击环形缓冲 `{source_id, skill_name, amount, t}`。

### 25.3 5 个 Autoload

`GameState`（局内运行时+境界+属性块+`active_roots`/`sealed_roots`）/ `SaveSystem`（user://save.json）/ `ConfigDB`（启动加载 Data/*.json）/ `AssetDB`（id→Texture+fallback）/ `SignalsBus`（事件总线）。`ConfigDB` 须先于 `SaveSystem._ready()`。

### 25.4 SignalsBus 关键接口

```gdscript

signal qi_collected(amount); signal stone_collected(amount)
signal boss_spawned(id); signal run_ended(result, stats)
signal market_offered(cards); signal market_choice(id)
signal weapon_changed(slot, weapon); signal stat_changed(stat, value)
signal roots_chosen(active_roots)
signal hud_request_shake(intensity, duration); signal hud_request_hitstop(duration)
```

### 25.5 collision_layer 表

| Layer | 名 | 用途 |
| --- | --- | --- |
| 1 | world | 边界结界 |
| 2 | player | 玩家本体 + Hurtbox |
| 3 | enemy | 敌人本体 + Hurtbox |
| 4 | player_weapon | 法器/剑灵/聚剑斩 Area2D |
| 5 | enemy_attack | 妖物投射/怨剑 |
| 6 | pickup | 灵气/灵石/精魄 |

### 25.6 性能

同屏 120+ 妖 + 8 法器实体 ≥ 60FPS。法器与剑光用**对象池**；命中检测优先距离平方裁剪，必要时空间网格；死亡敌人 `set_physics_process(false)`；DamageNumber 用 Tween 自动 free；FX 用 GPUParticles2D / 纹理动画。

| 4 | 武器品阶 | **保留 4 品**（凡/灵/法/仙）+ 神品⭐ | 合成/权重逻辑成熟 |
| 5 | 道具占位 | **3 件占 2 格**（凝神丹方/两仪剑佩/斩杀玉），其余 1 格 | 制造背包"广度 vs 强点"取舍 |
| 6 | 套装阈值 | **2 / 4 件**，做成"深度 vs 相生联动"对位 | 防止纯色成为唯一最优；强度靠 playtest 调 |
| 7 | 灵根中途解封 | **不解封** | 保持本局商店池恒为 3 系，设计/平衡最简 |
| 8 | 角色 | **仅云栖 1 个，无修正无解锁** | 把变量集中在灵根+构筑，降低首版复杂度 |
| 9 | 背包升级价 / 上限 | `14+8×n`，上限 10（占位） | 待与灵石收入曲线联调 |

> #6、#9 标注的数值在 playtest 后可调；其余为结构性定论，改动需同步更新 §6 / §8 / §9 / §19。
